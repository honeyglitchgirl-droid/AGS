# AGS-Sci EXP-2D-TURB-003-B

Locked 2D turbulence protocol.

- Spatial domain: periodic 2D
- Numerical precision: float64 / complex128
- Integrator: classical RK4
- Spectral representation: 2D FFT
- Dealiasing: configured by the 2D engine
- Scientific gates: deterministic budget, spectral, reproducibility, and stationarity checks

## Files

- `ENGINE_INVENTORY.md` — engine and dependency inventory
- `MILESTONE_CERTIFICATE.md` — experiment milestone record
- `EXP-2D-TURB-002_exact_gate.json` — locked gate configuration

This experiment is independent of the AGS core and uses the pluggable 2D research interfaces.
