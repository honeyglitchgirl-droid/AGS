# AGS-Sci v102 Geometric Engine

The production numerical research path is centered on periodic 2D spectral fields with explicit metric-aware geometry utilities.

## Implemented
- periodic spectral gradient/divergence/Laplacian/Poisson/Leray projection
- spherical and componentwise dealiasing modes
- normalized spectral-tail diagnostics
- metric raising/lowering and contractions
- constant-metric scalar box operator
- Abelian 1-form exterior derivative F=dA
- rank-2 tensor trace/double contraction/covariant divergence for constant metrics
- invariant scalar dictionary and vector advection builder
- deterministic resolution referee

## Scientific boundary
Software and numerical regression tests validate implementation contracts; they do not prove scientific hypotheses.
