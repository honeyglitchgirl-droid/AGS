# AGS-Sci v102.2.3 — CLEAN 2D RELEASE

This release is the clean 2D research baseline. The cumulative AGS scientific research stack is retained, while unfinished higher-dimensional experiment artifacts are excluded.

## Active numerical scope
- periodic 2D spectral fields
- 2D turbulence and forced-turbulence experiments
- RK4 integration
- spectral/dealiasing diagnostics
- deterministic resolution and scientific referees
- pluggable experiment, search, causal, epistemic, and active-inference layers

## Scientific boundary
Passing software tests validates implementation contracts; it does not prove scientific hypotheses or state-of-the-art performance.
